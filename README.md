Hey! This is my new project.

I've always loved combining C# with Unity because I feel very comfortable in that environment. And I absolutely love modding Minecraft Java. My skills aren't extraordinary. But they're definitely sufficient to do what I wanted.

Here's a reimplementation of the first version of Minecraft (Cave Game, rd-132211), written in C# in the Unity engine.

Believe me, this is a true reimplementation. The code is 100% mine, and I wouldn't even consider it a rewrite of Mojang's code, but I believe the game behaves practically identically.

I've recreated the physics, speed, and even the power of the jump, paying attention to the smallest details. My version is just better optimized. This way, it behaves practically identically.
